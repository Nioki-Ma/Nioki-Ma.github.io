
## How to Use

### Option 1: Open Locally
Simply open `index.html` in your web browser by double-clicking the file.

### Option 2: Use Live Server (Recommended)
If you have Python installed:
```bash
cd /home/local/ASURITE/ngong6/code/others/homepage
python3 -m http.server 8000
```
Then visit: http://localhost:8000

### Option 3: VS Code Live Server
1. Install "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

## Customization

### Update Content
Edit `index.html` to update:
- Personal information
- Projects
- Skills
- Contact details

### Change Colors
Edit `styles.css` at the top (`:root` section) to change the color scheme:
```css
--primary-color: #2563eb;
--secondary-color: #1e40af;
--accent-color: #3b82f6;
```

### Add More Sections
Follow the existing section structure in `index.html` and add corresponding styles in `styles.css`.
